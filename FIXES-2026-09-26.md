# EcoPulse AI — Final Runtime Fixes (2026-09-26)

## Fixed from live runtime logs

### AI investigation
- Updated default Gemini model from `gemini-2.5-flash` to `gemini-3.8-flash`.
- Supports `GEMINI_MODEL` environment override.
- AI status endpoint now reports the configured model.
- AI investigation automatically selects the highest-priority active anomaly when `/insights` is opened without a query parameter.
- The evidence pack remains deterministic and is supplied to Gemini for interpretation; basic metrics are not delegated to Gemini.

### Action Center
- Fixed PostgreSQL identifier quoting for `ai_insights."rawResponse"`.
- The previous error `column i.rawresponse does not exist` came from PostgreSQL folding the unquoted camelCase identifier to lowercase.
- Existing actions can now be listed, filtered, and moved through `OPEN → IN_PROGRESS → COMPLETED`.

### Outcomes
- Completed actions are now loadable because the Action Center query no longer fails.
- AI-linked actions expose their suggested resource and latest measured value, allowing the Outcome form to prefill the correct Before value.
- Outcomes remain restricted to completed actions.

## Gemini
Google's current Gemini API documentation shows `gemini-3.8-flash` for Node.js `@google/genai` `generateContent` and structured JSON generation.

## Demo path

1. Login with the demo account.
2. Open **AI investigations**.
3. EcoPulse selects the active electricity anomaly.
4. Click **Investigate with AI** (or let the page start the selected investigation).
5. Review calculated evidence and the AI explanation.
6. Create an action from a recommendation.
7. Move the action `OPEN → IN_PROGRESS → COMPLETED`.
8. Click **Record outcome**.
9. Enter the next reading.
10. Save and verify the observed change in the timeline.
